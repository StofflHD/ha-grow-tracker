# Grow Tracker for Home Assistant

Document your grow in Home Assistant – from seed or cutting to curing – across all of your grow locations.

*The user interface is available in English and German.*

## Features

- **Sidebar panel** – overview of all locations and plants, with every action right there
- **Locations** – tents, cabinets and chambers with type and Home Assistant area
- **Plants** – strain, breeder/cutter, phenotype; phase and location with editable history
- **Mother plants & cuttings** – take cuttings, create them as plants, keep them linked to their mother
- **Notes** – a diary per plant, also for past dates
- **Entities, actions and events** – flowering week, expected harvest and more for dashboards and automations

## Installation

Requires Home Assistant **2025.6** or newer.

1. HACS → **⋮ → Custom repositories**
2. Repository `https://github.com/StofflHD/ha-grow-tracker`, type **Integration**
3. Download **Grow Tracker** and restart Home Assistant
4. *Settings → Devices & services → Add integration → Grow Tracker*

Manual installation and details: [Installation](https://github.com/StofflHD/ha-grow-tracker/wiki/Installation)
